丹青院项目（/Users/zhaomingming/Documents/danqingyuan）2026-06-10 第一轮重设计决策：

**定位转变**：从"7日考试demo"转向宋代翰林图画院生活模拟养成（参考火山的女儿）。考试/秘阁解谜降级为养成循环中的节点事件。

已拍板的决策：
1. 每日 5 时段：晨课/上午/午间/下午/晚间（7天×5段=35决策点）
2. 剧情写作器（scene_narrator，第四个 LLM role）：关键行动（偶遇/首次场景/事件）调 LLM，日常重复行动用模板池；引擎先算结果，LLM 只写叙述
3. 好感度：进度条/心格显示，无具体数字；阈值解锁主界面 NPC 专属对话入口
4. 属性集：体力 + 心情 + 学识（新增后两项），行动后明确显示数值结算
5. 好感线只做希孟/择端/嵩；唐翁更名为李唐，定位导师/考官，无好感线（待最终确认）
6. NPC 出没表：地点×时段→出现概率（希孟常在书房，择端常去街市）
7. 小测重做为课堂事件链：跳转场景→当值导师出场→开场白→1题→点评→结算
8. 第7日硬约束：1~6日只有小测，第7日强制丹青试，通过→画正→解锁秘阁
9. 秘阁差异化："观察-收集-拼合"，线索来自前6日积累（街市调查/NPC对话/书房查证）
10. 货币系统（钱文）：轻量、仅市井消费体验（茶坊5文/听曲8文/夜市4文），每日点卯领例钱10文，上限99；不参与重大叙事、不gate主线；院内供应免费、出院消费花钱；UI显示具体数字（与好感不同）
