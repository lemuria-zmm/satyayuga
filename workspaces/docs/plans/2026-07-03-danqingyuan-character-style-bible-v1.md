# 第一部分 · Style Bible（风格圣经）

## 1. 风格定位

**北宋院体绘画 × 古风情感叙事 × 东方写实**。

一句话：*仿佛《千里江山图》《清明上河图》《瑞鹤图》里的人物活了过来。*

| 是 | 不是 |
|---|---|
| 北宋、工笔、绢本设色、院体、写实人物、温润、留白、雅致、文人气 | 武侠、仙侠、二次元国风、玄幻、3D 渲染、赛博、动漫 9 头身 |

## 2. 统一色板（全项目通用）

**主色**：米白 `#EFE3C8`、青绿（石青石绿，呼应千里江山卷）、黛青、灰蓝、木色。
**点缀**：浅金 `#C5A45B`、朱砂红（少量，印章/衣饰点睛）。
**墨色**：`#2C1E12`。
**避免大面积**：紫、荧光蓝、鲜红、高饱和绿、任何霓虹/荧光色。

> 青绿是本项目的"主题色"——希孟的千里江山卷、颜料碟、画室之光都用它；它也是"繁华"的视觉符号，与暗线的"黑暗"（暗褐/墨沉）形成一体两面。

## 3. 色彩脚本（时间×氛围统一色温）

| 情境 | 色温/基调 |
|---|---|
| 白日 | 暖米色天光，柔和，阴影浅淡透气 |
| 黄昏 | 暖金偏橙，长影，怀旧 |
| 夜晚 | 青蓝夜色 + 一点暖黄灯焰（油灯/烛），冷暖对比 |
| 雨天 | 灰青、低饱和，湿润反光 |
| 秘阁/暗线 | 幽暗，光只打在关键处（案上画卷），大面积墨沉留白 |

## 4. 光影规范

- **统一柔和自然光**。不出现强逆光、舞台光、赛博光、多光源夸张打光。
- **各地点固定光向**（生成同地点不同图时保持一致，附现有底图作参考）：
  - 院堂 = 右侧格窗光
  - 书房 = 左侧窗光（沉静含尘）
  - 后花园 = 顶部天光/散射
  - 街市 = 平光/顶光，通透
  - 宿舍夜 = 案头油灯单点暖光
  - 秘阁 = 立灯/门缝单点光，四周没入暗部

## 5. 镜头语言（景别使用场景）

| 景别 | 用途 |
|---|---|
| 特写 | 半身像表情、画卷/线索道具细节 |
| 近景 | 案头、道具、书房架、食堂碗箸 |
| 中景 | 角色-场景图（人物占 1/4~1/3 融入环境） |
| 中远/远景 | 通用场景、市井全景、建筑纵深 |

## 6. 构图规律

- 场景图遵循**前景—中景—远景**三层纵深（近景道具/中景主体/远景虚化环境）。
- **给文字/立绘让位**：VN 场景图中央或一侧留出可叠加半身立绘的空间；暗调页（引文/秘阁/揭卷）保留大面积深色留白供打字机文字。
- 长卷式全景（市井、骸游图）可用横向散点构图（仿宋画长卷）。

## 7. 材质规范

绢本（细腻绢纹 + 岁月包浆）、宣纸（毛边微卷）、木材（温润漆色/原木）、石材（太湖石/青砖苔痕）、青铜（包浆）、颜料（石青石绿如宝石质感）。统一"有年头、有温度"，避免塑料感/新崭崭。

## 8. UI 与场景融合

画卷、朱砂印章、题跋、木牌、笺纸为贯穿元素；白底道具/UI 图统一走 CSS `mix-blend-mode: multiply` 融入纸面（深色底上先垫浅纸圆片再 multiply）。

# 第二部分 · Character Bible（角色美术圣经）

## 9. 人物统一规范（所有角色都固定，不得越生越不像）

| 维度 | 规定 |
|---|---|
| 头身比 | **约 7.5 头身**（写实，非动漫 9 头身） |
| 肤色 | **东方暖白**，统一，不忽白忽黄 |
| 开脸 | 工笔清雅古典，五官比例固定（各角色见其页），神态含蓄内敛 |
| 服装 | 北宋衣冠（襕衫/直裰/圆领袍 + 幞头或束发），颜色/纹样/层数固定；剧情换装另立设定 |
| 饰品/道具 | 每角色固定专属识别符号（见各页），是角色辨识核心 |
| 光 | 柔和自然光，服从场景光向 |

> **玩家角色（主角）**：可自定义（性别男/女、年龄 18~60、本科画风山水/人物/界画）——主角**不出固定立绘**（第一人称视角，游戏中不露正脸）；本 Bible 只规范固定 NPC。若将来要出主角立绘，须做性别×画风的差分组，另立规范。

## 11. 表情规范（所有角色统一变化幅度，写实克制）

| 表情 | 眉 | 眼 | 嘴 | 备注 |
|---|---|---|---|---|
| **Calm** | 自然 | 平视 | 嘴角 0° | 所有表情的母版 |
| **Smile** | 舒展 | 柔和 | 嘴角 +10° | **不露八颗牙**，含蓄浅笑 |
| **Stern** | 轻蹙 | 锐利 | 压平 | 不愠不怒，是"正色/不愿谈" |
| **Sad** | 微垂 | 略失焦 | 微收 | 内敛哀色，非嚎啕 |
| **Surprise** | 微扬 | 略睁 | 轻启 | 写实微反应，非动漫夸张 |

> 全部在 Calm 母版基础上仅改面部，服饰/发式/构图/光完全不动（同会话带母版参考生成）。

## 12. 镜头规范

| 类型 | 规范 |
|---|---|
| **半身像**（VN 对话） | 胸口以上、**正面、直视玩家**（视线看向屏幕外）、浅米纯色底、肩宽/胸口高度/留白统一（便于 Live2D 换图） |
| **全身立绘**（闲聊页/官方标准） | 站姿三七侧身、重心自然、正面朝向偏一点 |
| **场景 CG**（角色-场景图） | 人物**绝不看镜头**，专注自己的事，保持沉浸感 |

## 13. Live2D 预留规范

所有半身像统一**肩宽、肩部位置、胸口高度、四周留白**，构图对齐，便于后续 Live2D 直接换图/切分。母版（Calm）定死后差分与之像素对齐。

## 15. 角色一致性铁律（AI 生成最重要）

1. 生成任何角色图，**引用该角色 Calm 母版**作参考，不重新文字描述。
2. 同一角色的半身像与场景图在**同一会话**或**带母版参考**下生成。
3. 人设（年龄/性别/身高/五官/专属道具）以本 Bible 为唯一真相；改动先改本文件。
4. 场景图人物不看镜头；半身像人物直视玩家——两套镜头语言不混。
5. 违反 canon 的历史雷区：**嵩必须是中年男性**（非姑娘）；**希孟必须是 17~18 少年**（非青年成人）；李唐是严师非慈祥老者。

## 16. 生产接入指引

- 生成顺序：**先定 4 位 NPC 的 Calm 半身母版**（连带出色卡）→ 各自表情差分 → 角色-场景图（引用母版）→ 通用场景 → 引文/秘阁 → P1 骸游图。
- 母版定稿后归档到 `/bust/bust-{npc}-calm.png` 作为全项目参考图，需求单（art-assets-p0）里的角色图一律以此为准。
- 本 Bible 为 v1.0；新增角色/剧情换装/主角立绘时升版并在此登记。
