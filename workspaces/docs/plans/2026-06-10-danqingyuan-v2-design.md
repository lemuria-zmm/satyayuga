# 丹青院 v2 设计文档 —— 画院生活模拟改版

**日期：** 2026-06-10
**性质：** 对 `2026-06-03-danqingyuan-mvp-design.md` 的重大修订。冲突之处以本文档为准；未提及之处（世界观、云起时锚点、防剧透规则、LLM 校验管线、记忆系统）沿用原文档。

**定位转变：** 从"7 日考试 demo"转向**宋代翰林图画院生活模拟养成**（参考《火山的女儿》）。玩家在画院过活生生的古代生活：上课、吃饭、娱乐、结识 NPC；丹青试和秘阁解谜降级为养成循环中的**节点事件**，不再是游戏主体。

---

## 1. 核心循环 v2

```
每日 5 时段生活（晨课→上午→午间→下午→晚间）
  ├─ 课程表：玩家自填晨课 + 自选行动
  ├─ 数值成长：体力 / 心情 / 学识 / 三技能，显式结算
  ├─ 地点偶遇 NPC → 分支选项 → 好感度 → 解锁深谈
  ├─ 随机小测：考官问答事件链
  └─ 第 7 日丹青试（硬约束）→ 晋升画正 → 秘阁终章
```

---

## 2. 时间系统：7 日 × 5 时段

### 2.1 时段定义

| 时段 | 内容 | 玩家选择 |
|---|---|---|
| 晨课 | 点卯 + 玩家自填课表的当日课程（§4），可能触发课堂小测 | 排课时选择；自由临摹日临场三选一 |
| 上午 | 自选行动 | 修习 / 调查 / 观画 / 请教 |
| 午间 | 午膳（选食单）+ 偶遇高发段 | 食单 5 选 1 |
| 下午 | 自选行动 | 同上午 |
| 晚间 | 娱乐（不限次数）/ 温书 / 就寝收日 | 娱乐卡不推进时间，就寝才入次日 |

- 7 天 × 5 段 = 35 个决策点。
- 每时段结束推进时间；体力不足时部分行动置灰。
- 第 7 日晨课被丹青试强制替换（见 §9）。

### 2.2 与旧版的差异

废弃"上午/下午 + 体力 6 点自由行动"的结构。行动不再单纯消耗体力换时间，而是**每时段必选一项**，体力决定可选范围。

## 3. 数值系统

### 3.1 基础属性

| 属性 | 范围 | 初始 | 恢复/变化 | 影响 |
|---|---|---|---|---|
| 体力 | 0~10 | 8 | 每日晨起恢复至 8（受晚间活动修正） | 低于行动需求时该行动置灰 |
| 心情 | 0~10 | 6 | 饮食、娱乐、偶遇、考试结果 | 修习效率修正；过低触发低压事件 |
| 学识 | 0~50 | 0 | 听课、夜读、书房查证、请教 | **小测/丹青试加成**（2026-06-12 已实现：引擎确定性 +floor(学识/5) 0~10 分，叠加 LLM 软加成）；**学识 ≥10 解锁书房深查**（2026-06-12 已实现，降级版不产线索）；秘阁部分线索（≥20，待秘阁重做轮） |

### 3.2 三技能成长公式

```
修习收益 = 基础 2
  + 1（心情 ≥ 8，神清气爽）
  - 1（心情 ≤ 3，心绪不宁）
  + 1（当日晨课为同科目，趁热打铁；按玩家自填课表判定，见 §4）
```

技能范围 0~99，沿用"技能 = 观察权限"的设计（山水→路径云水，人物→视线情绪，界画→秩序空间）。

### 3.3 显式结算 UI

每次行动结束，结算纸签浮出，例如：

> 山水 +3　体力 -2　心情 +1

好感度变化不出数字，只显示 `希孟 ──── 梅花瓣亮起` 式反馈（见 §7.4）。

### 3.4 货币：钱文（轻量系统）

**定位：** 只服务市井生活体验（听曲、吃茶、夜市），**不参与重大叙事、不 gate 主线进度**。所有主线必需行动（修习/考试/秘阁/深谈）永远免费。

| 规则 | 设计 |
|---|---|
| 收入 | 每日晨课点卯自动领**例钱 5 文**（2026-06-12 由 10→5 治通胀；结算纸签显示"例钱 +5 文"）。7 日总收入约 35 文，需在市井享受间权衡取舍 |
| 上限 | 99 文，溢出舍弃 |
| 消费 | 仅市井消费类活动卡（见 §5），钱不足时选项置灰并显示所需钱数。2026-06-12 增消费深度：赁书 6 文（学识+1）、买画材 10 文（下次成长行动收益+1 的一次性 buff） |
| 显示 | 主界面数值栏第四项，铜钱图标 + 具体数字（货币显示数字，与好感不同） |
| 出身钩子 | 商贩之家享**市井消费 8 折**（持续优势，见 §6.5）；折后价贯穿可负担过滤与扣款 |
| 叙事边界 | LLM 不得生成借钱/赌钱/贿赂等支线；剧情写作器可在叙述中提及花销的风味（"数过铜钱，挑了临窗的座头"） |

院内供应（膳堂食单、院中娱乐）一律免费——画院养士；出院消费才花钱——市井烟火。

## 4. 课表系统（玩家自填晨课）—— 2026-06-10 第三轮拍板，已实现

废弃院定固定课表。**全部课程由总教习李唐授课**（无好感线，见 §7.1）；玩家入院引导结束后在**课表页（SchedulePlanner）**自排 1~6 日晨课，第 7 日固定丹青试。

### 4.1 课程池（`content/courses.ts`）

| 课程 | 地点 | 固定收益 |
|---|---|---|
| 山水课 | 院堂 | 山水 +1，学识 +1 |
| 人物课 | 院堂 | 人物 +1，学识 +1 |
| 界画课 | 院堂 | 界画 +1，学识 +1 |
| 画理课 | 书房 | 学识 +2 |
| 自由临摹 | 院堂 | 临场三选一，自选技能 +1 |

### 4.2 排课约束（`validateCurriculum`，课表页实时校验）

- 第 1~6 日各排一格，填满才可呈上；第 7 日锁定为**丹青试**。
- **本科课 ≥ 3 节**（本科 = 表单所选画风，见 §6.5）。
- 其余两画科选修**合计 ≥ 2 节**（画理课/自由临摹不计入选修额度）。
- 未填课表时晨课无可选行动（流程上排在引导之后，正常不会出现）。

### 4.3 联动规则

- **修习加成**：当日晨课与修习科目相同 → 修习 +1（§3.2 公式，按玩家课表判定）。
- **考试加权**：丹青试出题 `relatedSkills` 由 `getStudiedSkills(curriculum, 本科)` 给出——按各技能修课次数排序，本科保底计 1。排得多的科目考得多。
- 晨课结束后 **20% 概率**李唐留堂小测（§8）。
- 晨课走剧情写作器两阶段场景（§6）；LLM 失败时回落课程模板叙述（李唐口吻）。

## 5. 活动卡内容池

所有可选行动统一为**活动卡**结构：

```ts
ActivityCard {
  id, label, timeSlots,        // 可用时段
  locationId,                  // 跳转场景
  staminaCost / staminaGain,
  moneyCost?,                  // 钱文消费（仅市井消费卡）
  effects: { skills?, mood?, knowledge? },
  encounterPool?,              // 可能偶遇的 NPC 事件池
  narrator: 'llm' | 'template',// 剧情文本来源
  narratorTags,                // 给剧情写作器/模板池的素材标签
  dailyLimit?, requires?       // 次数限制、前置条件（学识/职级/flag）
}
```

**行动签与地点对应（2026-06-11 拍板）**：行动签只显示**当前地点**本时段的活动卡（`getAvailableActions` 按 `locationId === currentLocation` 过滤）；走动免费不耗时段，即「换地方 = 换可做的事」。例外：晨课/丹青试必到，各处可见（点击自动前往）。「修习山水/人物/界画」三签**已去除**——画技成长走晨课（含自由临摹三选一）+ 街市写生/后花园观景附带收益。地点本时段无签时显示提示「此处此刻无事可做」。

## 6. 剧情写作器（第四个 LLM Role）—— v4（2026-06-10 三轮拍板，已实现）

### 6.1 职责与边界

`scene_narrator`，与三件套并列。**引擎先算结果，LLM 只写文 + 一轮分支互动。** 现有三个 phase：

0. **phase = "intro"**：入院转场引文（仅开局一次，见 §6.6 入院流），无分支无 patch。
1. **phase = "open"**：LLM 根据玩家档案 + 事实清单 + 在场 NPC 写开场段（≥200 字），段末落在一个需要玩家回应的瞬间，并给出 2~3 个分支选项（每项 ≤25 字，互有真实差别）。
2. 玩家点选分支，**或自由输入**（≤40 字）。
3. **phase = "resolve"**：LLM 承接 `openNarrative` + `playerChoice` 写收束段（≥200 字），可输出 `suggestedPatch`（小幅状态建议）与 `memoryNote`（≤50 字关键事件摘要）。出格的自由输入在剧情内温和化解，不顺着演。

**引擎裁决（clamp）上限：**

| 建议项 | 上限 |
|---|---|
| `moodDelta` | -1 ~ +1（取整） |
| `affinityDeltaByNpc` | 每人 -2 ~ +3，**仅限在场 NPC，键必须用 npc id**（如 `litang`），姓名键直接剔除 |
| `clueIds` | 仅限引擎给定的 `allowedClueIds` 白名单 |

**记忆白名单（引擎判定）**：`memoryNote` 非空且 ≤50 字才写入剧情账本（storyLedger），否则丢弃。

### 6.2 输入 / 输出（实现版）

```ts
SceneNarratorInput {
  phase: 'intro' | 'open' | 'resolve',
  day, timeSlot, locationId, weather, season,
  player: { name, genderLabel, age, originLabel, personalityLabel, aspiration, styleLabel, romanceLabel },
  actionLabel,                 // "晨课·山水课" "街边吃食"
  facts: string[],             // 引擎已结算的事实清单，不得增删改
  themeBeat,                   // 「粉饰太平」当日节拍（当日浓度上限）
  mainlineBeat?,               // 七日主线当日节拍（§6.7），一场至多落一笔
  prevSceneEnding?,            // 上一场结尾 80 字锚点（治割裂，开场须承接）
  todayPlan?,                  // 今日课表/现下时段/明日摘要（自然提及，不复述）
  npcsPresent: Array<{id, name}>,  // 引擎掷点决定在场，不在此列不得出场
  lengthBudget: { segmentMin, segmentMax, dayCharsUsed, dayCharsMax },
  openNarrative?, playerChoice?,   // resolve 阶段
  allowedClueIds?,                 // resolve 阶段线索白名单
  playerStyleTags, recentLedger, canonWarnings
}
SceneNarratorOutput {
  narrativeText,               // ≥segmentMin 字
  choices?,                    // open 必填 2~3 项；resolve 禁止
  suggestedPatch?, memoryNote?, // resolve 专用；open 禁止
  atmosphereTags?              // 仅供 UI 氛围用，不入状态
}
```

校验在 proxy 端按 phase 分流（`validateLlmOutputForRole` 带 input）：字数边界、choices 数量与长度、patch 数值范围、npc id 合法性、线索白名单、memoryNote 长度，外加剧透扫描（正文 + choices + memoryNote）。重试耗尽回退模板（结算纸签仍照常显示），不卡玩家。

**场景衔接（治割裂，prompt v4 新增）：** 开场第一笔须承接 `prevSceneEnding` 的动作/心绪（不复述原句）；`todayPlan` 只作背景认知自然带过；`actionLabel` 必须在开场第一段落到实处；resolve 结尾留一句向后的余味（收拾纸笔、起身往何处去），供下一场承接。prompt 版本 `scene_narrator@2026-06-10.v4`。

### 6.3 字数预算与调用时机

- 每段 ≥200 字、≤500 字；**一日剧情合计约 2000 字，硬上限 3000 字**（`TimeState.narrativeCharsToday` 跨日清零）。当日预算 + 200 超过 3000 时跳过 LLM 场景，直接走模板结算。
- 每场景固定 1 轮分支（open → 选择 → resolve），一日 5 时段 ≈ 10 段，分支选项 ≥5 个/日自然达成。
- **体力归零 → 强制就寝 → 直接进入次日晨课**（第 7 日则进入终章），引擎附一句过场叙述。

| 场景 | 来源 |
|---|---|
| 全部时段行动（晨课/修习/活动卡） | LLM 两阶段场景 |
| 走动（移动） | 模板 |
| 当日字数预算将满 | 跳过 LLM，模板结算 |

### 6.4 主题暗线「粉饰太平」

七日递进节拍表（`THEME_BEATS_BY_DAY`）：第 1 日繁华表层 → 第 7 日太平之问（丹青试画太平气象，画或不画都是回答）。每场至多轻点一笔，阴影要具体而小（被克扣的一文工钱、不敢入画的景象），不发议论、不替玩家下结论；`themeBeat` 是当日浓度上限，不得超前。

### 6.5 玩家档案接入 —— 表单 v3（2026-06-10 三轮拍板，已实现，存档 schemaVersion 4）

开局表单收集：

| 项 | 设计 |
|---|---|
| 姓名 / 性别 | 自由输入 / 男·女 |
| 年龄 | **滚轮 18~60**。`getRomancePolicy(age)`：>50 岁希孟线转**忘年知己**（platonic）；≤50 恋爱开放、不限性别 |
| 家庭背景 | 5 选 1，轻微影响初始数值（见下） |
| 性格 | **自由输入**（不再 4 选 1），直接入玩家档案供写作器用 |
| 画风（本科） | 三选一：山水/人物/界画（**去掉「均衡」**）。决定课表本科约束（§4.2）与引路人（§6.6） |
| 未来志向 | 自由输入，剧情推演的罗盘（先生提问、同窗议论暗暗呼应），七日里偶尔照见即可 |

家庭背景初始效果（一次性）：商贩之家 钱+5；耕读之家 学识+3；官宦旁支 钱+5 学识+2 心情-1；匠作之家 界画+2；流民出身 体力上限+1 钱-5。

**出身持续优势（2026-06-12 新增，三出身有持续钩子）：** 商贩之家——市井消费 8 折（贯穿生成/扣款/可负担过滤/UI）；耕读之家——学识类收益 +1（查证/夜读/晨课画理）；匠作之家——界画成长 +1（界画课/写生）。官宦旁支、流民出身保留一次性修正（流民的体力上限本身即持续优势）。**设计意图：** 让出身选择产生「这一局会怎么不一样」的可预期路径，而非一次性小加成。

### 6.6 入院流与第 1 日教程流（2026-06-11 第五轮拍板，已实现）

```
表单 → 轻量转场页 AdmissionTransition（小书童立绘；scene_narrator phase=intro 生成入院引文，失败回模板）
```

## 7. NPC 系统

### 7.1 角色定位调整

- **唐翁 → 李唐**：定名李唐（美术资产已用 `char-litang`）。定位**全员总教习 / 监考官**（授课全部 5 门课程，见 §4），无好感线，互动形式是"请教"（数值回报）与课堂表演。
- **好感线三人组：希孟、择端、嵩。** 三人兼任各科引路人（§6.6）。

### 7.2 NPC 出没表

`NPC × 地点 × 时段 → 出现概率`，引擎在玩家进入地点行动时 roll 偶遇：

| NPC | 高概率 | 中概率 | 低概率 |
|---|---|---|---|
| 希孟 | 书房·上午 35% | 书房·晚间 25%，后花园·午间 20% | 听琴·晚间 10% |
| 择端 | 街市·上午/下午 40% | 瓦子·晚间 30%，膳堂·午间 20% | 院堂·下午 10% |
| 嵩 | 院堂·下午 30% | 街市·午间 25%，投壶·晚间 20% | 书房·上午 10% |
| 李唐 | 晨课（总教习，固定在场） | 书房·下午 25%（请教） | 弈棋·晚间 15% |

规则：每时段最多触发 1 次偶遇；同一 NPC 每日最多 1 次好感偶遇；"与同僚共膳"卡必触发一次判定。

### 7.3 偶遇事件结构（四阶段）

```
1. 引子    剧情写作器生成场景叙述（NPC 在做什么）
2. 分支    2~3 个固定模板选项（按 NPC 好感阶段与已解锁话题筛选）
3. 反应    NPC 回应：短模板 + 角色对话器润色（沿用现有 character_dialogue role）
4. 结算    好感Δ（好 +3 / 中 +1 / 差 -2）、可能授予线索卡、解锁话题
```

偶遇事件做成内容池（每 NPC 首批 6~8 个），带前置条件（日次/好感档/flag），保证不重复且随关系推进换批。

### 7.4 好感度

- 内部数值 0~100，**UI 显示为 5 瓣梅花**（每 20 点亮一瓣），不出数字。
- 档位沿用原命名：陌路 0-19 → 同僚 20-39 → 同道 40-59 → 知己 60-79 → 莫逆 80+。
- **阈值解锁：好感 ≥ 20（同僚），主界面出现该 NPC 的专属深谈入口**——现有 DialogueScreen 移到这里，成为解锁奖励而非随时可点的闲谈。
- 深谈每日每 NPC 限 1 次，体力 -1；话题卡随好感档解锁，自由追问保留 1 轮。
- v2 目标进度：7 日内希孟可达"同道"（解锁秘阁剧情反应增强），择端/嵩可达"同僚~同道"。

## 8. 小测（课堂试）流程 v2

废弃"点按钮直接弹题"的形式，改为**事件链**：

```
触发（晨课后 20% 留堂 / 主界面"请试"按钮，每日限 1 次，体力 -1）
  → 跳转课堂场景（院堂）
  → 考官出场（**总教习李唐统一监考**，立绘 + 开场白）
  → 画题生成器出 1 题（题型按当日课程科目）
  → 玩家作答（三选项 + 自由输入，沿用现有题卡）
  → 考官当面点评（评估器输出，李唐冷峻口吻）
  → 结算：对应技能 +1~2，学识 +1，心情 ±1
```

技术要点：ExamScreen 增加 NPC 立绘与对话阶段；`painting_intent_evaluator` 输入增加 `examinerPersona` 字段，visibleFeedback 必须以考官口吻输出。

与丹青试的差异：小测 = 单题 / 低风险 / 日常 / 课堂场景；丹青试 = 双题 / 晋升判定 / 仪式感 / 考场场景。

## 9. 第 7 日丹青试与硬约束

- **第 1~6 日：** 只能小测，`take_exam` 行动不存在。
- **第 7 日晨课强制替换为丹青试**，不可跳过、不可回避。监考李唐，双题（沿用现有出题/评阅管线），通过线 60 分。
- **通过：** 晋升画正 → 当日下午解锁秘阁（`archiveUnlocked` 只能由此路径写入，移除现有"任意考试通过即解锁"的逻辑）。
- **失败：** 下午触发导师补习（弱项技能 +2，剧情文本），晚间可申请补试一次（单题，通过线 60）；再败则进入"留院再修"结局钩子，MVP 流程结束。

## 10. 秘阁终章 v2：观察 → 收集 → 拼合

### 10.1 与考试页的本质区别

秘阁不是答题，是**实图解谜**。三幕结构：

| 幕 | 玩法 | 界面 |
|---|---|---|
| 一 观画 | 在《骸游图》实图上点热点，找 3 处异常 | 解谜页场景图 + 热点环（素材已有） |
| 二 拼线索 | 打开线索匣，选 ≥3 张线索卡组合 | 线索匣面板（素材已有） |
| 三 成读 | 自由输入解读 + 提交，评估三档反馈 | 沿用评估管线 |

### 10.2 线索来自前 6 日积累（养成-解谜闭环）

候选线索卡 8 张，来源分布：

| 来源 | 张数 | 获取方式 |
|---|---|---|
| 街市写生/听曲 | 2 | 货郎药瓶、摊位朝向 |
| NPC 对话/偶遇 | 3 | 希孟（水路敏感）、择端（市井秩序）、嵩（被记录的人） |
| 书房深层查证（学识 ≥10） | 2 | 旧批注、画卷档案 |
| 丹青试余韵 | 1 | 残画题"水路断处起云"（弱伏笔 1） |

- 进入秘阁后**时间压力停止**（终章自由行动）：线索不足可暂退，去各地点补集（每地点限 1 次），再回秘阁提交。
- 评估三档与"云起时"伏笔规则全部沿用原文档 §7。
- 集齐 ≥6 张线索 + 核心档解读 → 强化版结尾钩子（希孟反应 + 第二幅画卷露出更多）。
