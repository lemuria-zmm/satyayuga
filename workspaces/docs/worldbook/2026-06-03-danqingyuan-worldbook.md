# 丹青院 MVP 世界书

**用途：** 为 LLM 调用提供按需检索的世界观、地点、制度、画卷、道具与线索设定。世界书属于“事实层”，不同于角色卡的“表演层”和剧情圣经的“真相层”。

**使用方式：** 每次 LLM 调用只加载与当前场景、题目、NPC、画卷或线索相关的条目。不要把整份世界书全部塞入上下文。

---

## 1. 条目格式

每个条目建议保留以下字段：

```text
ID:
名称:
类型:
玩家可见说明:
隐藏说明:
关联角色:
关联线索:
适用 LLM:
禁止误用:
```

### 类型枚举

- `地点`
- `制度`
- `职级`
- `技能`
- `画卷`
- `道具`
- `线索`
- `术语`
- `事件`
- `伏笔`

### 适用 LLM 枚举

- `角色对话器`
- `画题生成器`
- `画意评估器`

## 2. 世界与制度

### 2.1 丹青院

```text
ID: place_danqingyuan
名称: 丹青院
类型: 地点
玩家可见说明: 归属内廷的宫廷绘事机构，聚集画师、考生、导师和封存画卷。玩家入院后在此修习、应试、结识 NPC，并逐渐接触秘阁。
隐藏说明: 丹青院不只是为宫廷作画，也保存了许多不宜公开的画卷与记忆。院中制度表面严整，背后有对民生、灾异和政治压力的复杂记录。
关联角色: 希孟, 择端, 唐翁, 嵩, 玩家
关联线索: 秘阁, 丹青试, 职级晋升
适用 LLM: 角色对话器, 画题生成器, 画意评估器
禁止误用: 不要使用真实历史机构名；不要把丹青院写成现代学校或纯恋爱学院。
```
