# 丹青院 · 世界观重构 canon（2026-06-30）

> 本文件是「世界观/解谜线重构」后的**单一真相源**，所有 prompt 与 content 改动以此为准。
> 取代旧设定中的「云起时」隐藏地点线。改动依据：明明 2026-06-30 拍板。

## 一、真相层级（从玩家可见 → 最深）

| 层 | 内容 | 玩家何时/如何接触 |
|---|---|---|
| **L0 玩家的疑问**（穿越 framing） | 玩家是现代人，带着一个史实谜题穿越入院：**王希孟画完《千里江山图》后，为何从记载中消失？**（半架空：游戏里画作名作《千里江山卷》） | 入院页明说 + 入院引文 |
| **L1 千里江山卷**（明面） | 希孟公开在画的青绿山水长卷（原型《千里江山图》），要进献宫里、呈"盛世气象"。院里人人皆知。 | 希孟日常对话主谈此卷 |
| **L2 繁华与黑暗的交织**（社会暗线） | 汴京表面繁华盛世，底下是民生疾苦、搜刮、亡国前奏。原「粉饰太平」主题改名为此。 | 街市见闻/写生/市井闲话（随机母题线 A） |
| **L3 骸游图**（导师暗线） | 希孟、择端、李唐、嵩**四人共创**，分工不同——有人执笔作画、有人不直接画而是**定立意**。画的是盛世底下的疮痍，本意**欲进献以警戒皇帝当朝危局**（警戒目的 MVP 剧情中先不点明）。希孟一边画光鲜的千里江山卷、一边参与骸游图——两幅画正是"繁华与黑暗"的一体两面。 | 书房线索 + 希孟深聊埋线，**第 7 日开秘阁见骸游图才收束揭开"四导师共创"** |
| **L4 希孟的消失**（终极钩子） | 与骸游图有关（政治迫害 / 为自保隐退），**MVP 绝不给定论**，只埋钩，留玩家探索。 | 书房线索 + 知己对话留钩，不坐实 |

## 二、两条暗线并行

- **线 A（社会·随机）**：保留 `mainlineSeeds` 随机母题机制，作街市见闻暗线。主题名 = 「繁华与黑暗的交织」。
- **线 B（骸游图 + 希孟·固定）**：新固定暗线，载体 = 书房线索 + 希孟对话分档 + 秘阁收束。

## 三、希孟对话分档（好感软线索，主载体）

- **陌路 / 同僚**：只谈千里江山卷（构图、青绿、要进献的盛世气象），寡言克制。
- **同道**：松口——"有些景，画了也不能进献"；提到院里几位先生偶尔聚在一处，不谈笔墨谈别的。
- **知己**：吐露——除了千里江山卷，"还有一幅画，不是给该看的人看的"；并埋消失钩"若有一日我不在了，这卷青绿……"（点到即止，不解释为何会不在）。
- **莫逆**：近乎交底但**不点破**——四人共做一件事、那幅画记的是什么，仍只在言外。

## 四、书房线索（克制方案·3 条）

1. **旧档同名**（基础，library 普通查证/深查文案）：四位导师的名字在某几页旧档里反复同时出现，像在共事一桩没记入册的事。
2. **涂改题记 + 草图**（学识≥10，`library_deep_research` 深查）：一函旧批的题记年月被涂改，夹着半张草图——画的是流民疾苦，与千里江山卷的青绿盛世截然相反。
3. **撞见另一卷**（希孟好感≥同道 且进书房，软触发）：撞见希孟案上压着千里江山卷之外的另一卷，他匆匆收起。

→ 三条都只埋线、不坐实；秘阁见骸游图时收束为"四导师共创、记录真相"，消失之谜与警戒目的仍留钩。

## 五、穿越 framing 的技术处理（防 NPC 泄露）

- 穿越疑问是**全游戏固定前提**（非每人不同的输入）：放在入院页明说 + 入院引文。
- `aspiration`（未来志向）字段**保留作世俗志向**，照旧喂 prompt。
- prompt 里穿越疑问标注为**玩家私有心结、NPC 不知情、不可由 NPC 直接说破**；至多让玩家对希孟去向的"格外在意"在剧情里隐隐成立。

## 六、废弃项（旧「云起时」线）

- 废 `motif_water_end_cloud_rise`（水穷云起 motif）、`hiddenAnchor: cloud_rise_time`（云起时 codename）。
- 各 prompt 叙事边界里「云起时是隐藏地点 / 水穷云起只作伏笔」整段删除，改为骸游图导向的边界（见下）。
- 残画考题文案、`noticedWaterEndCloud*` flag → 重命名/改为骸游图觉察语义（见 task 16）。

## 七、改完后的统一叙事边界（替换各 prompt 旧边界）

- 世界是架空北宋宫廷画院「丹青院」。
- 玩家是带着"希孟为何消失"之谜入院的过客（**此为玩家私有，NPC 不知**）。
- 希孟明面画《千里江山卷》（进献盛世），背后参与《骸游图》。
- 《骸游图》=希孟/择端/李唐/嵩四人共创、分工不同（含只定立意者），记盛世底下疮痍。**不得说成某一人独作**；**MVP 中不点明"进献警戒危局"的目的、不坐实希孟消失原因**。
- 第 7 日开秘阁见骸游图前，不揭"四导师共创"；任何时候不坐实希孟消失之谜。
